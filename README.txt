LA CASA BLANCA — ACTIVIDAD PRÁCTICA 01 (SENA)
Landing page en HTML5, CSS3 y JavaScript
========================================

ESTRUCTURA DEL PROYECTO
- index.html: página principal con comentarios en cada sección.
- css/styles.css: estilos visuales responsive en tonos blanco, negro y azul.
- js/script.js: filtro de productos, búsqueda, carrito, formulario y menú móvil.
- img/logo-casa-blanca.svg: logo vectorial de demostración creado para este proyecto.
- img/logo-inspiracion.png: imagen gráfica de inspiración para la sección Quiénes somos.

REQUISITOS DEL PDF INCLUIDOS
- Estructura básica HTML5 y etiquetas semánticas.
- Header con título, logo, subtítulo y navegación.
- Secciones de Inicio, Quiénes somos, Servicios, Productos, Contacto, pagos y ubicación.
- Imagen representativa con atributos src y alt.
- Lista ordenada con seis beneficios.
- Contenido multimedia con etiqueta video.
- Tabla con cinco columnas y doce filas de productos (más encabezado).
- Mapa de Google Maps con iframe.
- Formulario con nombre, apellidos, fecha de nacimiento, edad, dirección, correo, teléfono y mensaje.
- Footer con contacto, enlaces de navegación, redes sociales y derechos de autor.
- Código comentado y organizado en archivos separados.

CÓMO ABRIR EN VISUAL STUDIO CODE
1. Extrae el archivo ZIP en una carpeta.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta y elige la carpeta la_casa_blanca_entrega.
4. Abre index.html.
5. Puedes abrir index.html directamente en el navegador o instalar Live Server y elegir “Open with Live Server”.
6. Se necesita conexión a Internet para cargar Google Fonts, el mapa y el video de demostración.

ANTES DE PUBLICAR
- El correo hola@lacasablanca.example y el WhatsApp +57 300 000 0000 son datos ficticios de ejemplo; reemplázalos por datos reales.
- El dominio .example no recibe correos.
- La ubicación de Medellín es de referencia; cambia el mapa si el negocio está en otro lugar.
- Los precios son ilustrativos en pesos colombianos.
- El formulario abre un borrador en la aplicación de correo del visitante; no guarda datos en una base de datos.
- El carrito es una demostración front-end: no procesa pagos reales ni almacena pedidos en un servidor.
- El video enlazado es un recurso de demostración ajeno al negocio; sustitúyelo por un video propio o autorizado si tu instructor lo requiere.
- Los enlaces a Instagram, Facebook y TikTok dirigen a sus páginas generales; sustitúyelos por los perfiles de la marca cuando existan.
- La Casa Blanca se presenta como fan page independiente, no afiliada oficialmente al Real Madrid CF.
